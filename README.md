# PCStore — Магазин за компютърни части

Онлайн магазин за компютърни компоненти, изграден с Laravel 11 и PHP 8.3+.  
Проектът включва пълнофункционална витрина за клиенти и административен панел за управление на продукти, категории и поръчки.

---

## 🔧 Изисквания

Преди да започнеш, увери се, че имаш инсталирани:

| Инструмент | Минимална версия | Проверка |
|------------|------------------|----------|
| **PHP** | 8.2+ (препоръчително 8.3) | `php -v` |
| **Composer** | 2.x | `composer -V` |
| **Node.js** | 20+ | `node -v` |
| **npm** | 10+ | `npm -v` |
| **SQLite** | 3.x | идва с PHP |
| **MySQL/MariaDB** | 8.0+ / 10.4+ | по избор |

> 💡 **Най-лесният вариант за Windows:** инсталирай [Laravel Herd](https://herd.laravel.com/) — той включва PHP, Composer, Node.js и локален сървър.
